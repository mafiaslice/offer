# Icons

Offer draws interface icons from [Rune Icons](https://github.com/Runeicons/runeicons). The icon SVGs are Apache 2.0 and need no attribution. Offer does not depend on an icon npm package.

## Source

| | |
| --- | --- |
| Repository | [github.com/Runeicons/runeicons](https://github.com/Runeicons/runeicons) |
| Branch | `main` |
| Outline | `public/normal` |
| Active navigation | `public/fill` |

Raw files are copied into [`components/icon.tsx`](../components/icon.tsx). Each glyph keeps the 24×24 viewBox. Stroke colors (`black`, `#1C1F21`) and fill plates (`#DDDDDD`) are rewritten to `currentColor`, so icons follow the existing purple, lavender, black, and white text color. Fill plates use `currentColor` at 35% opacity so the stroke stays visible on light and dark surfaces.

Size icons with Tailwind on that grid: `size-4` (16px), `size-5` (20px), or `size-6` (24px). Do not introduce a second viewBox.

`public/fill` has no `plus` file. Post a Gig stays the outline `plus`. The purple nav button is the filled chrome.

## Not swapped

These are not Rune glyphs:

- Empty states and error screens (`empty-state`, Discover load/empty copy, `app/error.tsx`, `app/not-found.tsx`) are text only.
- Check-in QR is generated by `uqr` in `components/check-in-qr.tsx`.
- The status check inside `components/save-button.tsx` and the scroll arrow inside `components/scroll-stack-deck.tsx` stay as shipped with the useLayouts components (`save-button`, `multi-step-form`, `holographic-referral-card`, `scroll-stack-deck`, `star-showcase`).
- Typographic separators (`•`) and empty counts (`—`) are not icons.
- `app/icon.tsx` is the Offer letter mark, not a UI glyph.

## Add a new icon

1. On `main`, open `public/normal/<category>/<name>.svg`. Copy a `public/fill` file only when an active state needs the filled plate and that file exists.
2. Add the name to the `IconName` union in `components/icon.tsx`.
3. Paste each `<path>` into `outlines`. Set `stroke` to `"currentColor"` and keep `strokeWidth`, `strokeLinecap`, and `strokeLinejoin` from the file. Drop hardcoded `black` / `#1C1F21`.
4. For a fill variant, add the same name under `filled`. Plate paths that were `fill="#DDDDDD"` become `fill: "currentColor"` and `fillOpacity: 0.35`. Stroke paths stay `currentColor` with no fill.
5. Render `<Icon name="the-name" className="size-5" />`. Pass `filled` for an active state. Color comes from the parent text color (`text-purple`, `text-black`, `text-white`, `text-purple-gray`).
6. Add a row to the mapping table above.

Do not add an npm dependency for icons.
